# 전송형 전자영장 집행포털 입출금내역제공내역 일괄변환 프로그램

> **거래내역 1·2 합치기 — 엑셀 거래내역을 수사관이 확인하기 편한 형태로 정리하는 Windows용 업무 편의 프로그램**

전송형 전자영장 집행포털을 통해 제공받은 `입출금내역제공내역.xlsx` 파일은 한 행에 **거래내역 1과 거래내역 2가 좌우로 나란히** 기록될 수 있습니다. 이 구조에서는 거래 흐름을 시간 순서대로 살펴보거나 필요한 열만 추려 확인하기가 불편합니다.

이 프로그램은 각 행의 두 거래를 **거래1 → 거래2 순서로 세로 배치**하고, 열 선택·서식·필터를 적용한 엑셀 파일을 생성합니다. 원본 파일은 덮어쓰지 않습니다.

## 변환 전후

**변환 전**

| 원본 행 | 공통정보 | 거래내역 1 (V~BA) | 거래내역 2 (BB~CG) |
|---|---|---|---|
| 4행 | 동일 공통정보 | 거래 A | 거래 B |
| 5행 | 동일 공통정보 | 거래 C | 거래 D |

**변환 후**

| 변환 행 | 공통정보 | 거래내역 |
|---|---|---|
| 첫 번째 거래행 | 공통정보 | 거래 A |
| 두 번째 거래행 | 공통정보 | 거래 B |
| 세 번째 거래행 | 공통정보 | 거래 C |
| 네 번째 거래행 | 공통정보 | 거래 D |

거래2의 거래코드가 `0`이거나 비어 있는 경우, 해당 거래2 행은 만들지 않습니다. 거래 영역이 완전히 비어 있는 경우도 제외합니다.

## 주요 기능

- **여러 파일 일괄 변환**: 파일 선택 또는 드래그 앤 드롭으로 `.xlsx` 파일 여러 개 추가
- **프리셋별 실행 버튼**: `변환(전체)`, `변환(기본 프리셋1)` 및 저장한 사용자 프리셋 버튼 자동 표시
- **필요한 열만 출력**: 기본 프리셋1은 `K, L, V~AM`을 대상으로 하며, 환경설정에서 개별 열 선택·저장·삭제 가능
- **입금·지급 구분**: 행 전체에 색상을 적용할 수 있으며, 기본 설정은 **지급 거래만 연주황색** 표시. 색상 프리셋과 개별 색상 설정 지원
- **가독성 개선**: 거래일자·시간 분리, 금액 천 단위 구분, 자동필터, 열 그룹 접기, 글꼴·테두리·인쇄 서식 적용
- **원본 보존**: 변환 결과는 원본과 같은 폴더에 새 파일로 저장. 같은 이름이 있으면 `_변환2`, `_변환3`처럼 번호 부여

## 결과 엑셀의 시트 구성

| 시트명 | 내용 |
|---|---|
| `변환(요약)` | 실행한 버튼/프리셋에 따라 선택된 열만 보여주는 정리 시트 |
| `변환(원본칼럼 유지)` | 원본 A~CL 열 구조와 1~3행 머리글을 유지하면서 거래1·2를 세로로 배치한 시트. 옮겨온 거래2의 원래 오른쪽 데이터 영역은 공란 처리 |
| `원본시트` | 제공받은 원본 시트 데이터를 보존한 시트 |

`변환(원본칼럼 유지)`와 `원본시트`에는 3행을 기준으로 자동필터 및 머리글 고정이 적용됩니다.

## 사용 방법

1. [Releases](../../releases)에서 배포된 프로그램을 받습니다. **EXE가 첨부되어 있는 경우** 압축을 해제하거나 파일을 저장하여 실행합니다.
2. 프로그램에서 **엑셀 파일 추가** 버튼을 누르거나 파일을 목록에 끌어다 놓습니다.
3. `변환(전체)`, `변환(기본 프리셋1)` 또는 사용자 프리셋 버튼을 선택합니다.
4. 원본 파일과 같은 폴더에서 `원본파일명_변환.xlsx` 결과를 확인합니다.
5. 필요한 경우 **환경설정 · 컬럼/색상**에서 표시할 열과 색상을 조정하고 프리셋으로 저장합니다.

예시: `입출금내역제공내역.xlsx` → `입출금내역제공내역_변환.xlsx`

> **주의:** 이 저장소에 EXE가 아직 게시되지 않았다면 아래의 소스 빌드 방법을 이용해야 합니다. GitHub에 소스만 올린 상태로는 EXE를 바로 실행할 수 없습니다.

### 소스에서 Windows EXE 만들기

빌드 패키지에 포함된 `Build_EXE.bat`를 Windows에서 실행하면 PyInstaller로 단일 실행파일을 생성하도록 구성되어 있습니다. 빌드 PC에는 Python과 패키지 설치를 위한 네트워크 접속이 필요할 수 있으며, EXE는 `dist` 폴더에 생성됩니다. 배포 전 사용하는 Windows 환경에서 직접 실행·변환 테스트를 권장합니다.

## 설정파일

열 선택 프리셋과 색상 설정은 프로그램 실행파일과 같은 폴더의 다음 파일에 저장됩니다.

```text
TransactionConverter_Settings.json
```

사용자 프리셋을 다른 PC에서도 이용하려면 이 설정파일을 실행파일과 함께 복사하세요. 설정을 저장할 폴더에는 쓰기 권한이 있어야 합니다.
